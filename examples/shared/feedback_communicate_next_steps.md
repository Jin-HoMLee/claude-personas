---
name: Communicate next steps proactively
description: Always tell the user what the next step is after completing an action, so they can anticipate and understand the flow
type: feedback
---
After completing each action, always state what the next step is before waiting for the user to ask.

**Why:** Helps the user anticipate the sequence of work and understand why each action is being taken. Avoids confusion when steps have dependencies (e.g. needing to merge a PR before a prod run).

**How to apply:** End each completed action with a one-liner like "Next: [action]" or ask "Want me to do X next?" — especially when there are multiple dependent steps in a sequence.
