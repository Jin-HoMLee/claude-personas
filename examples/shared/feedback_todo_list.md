Always create a TodoWrite task list at the start of any multi-step session and keep it updated in real time — mark each task in_progress before starting it and completed immediately after finishing.

**Why:** The user finds it helpful to see the full sequence upfront so they can anticipate what's coming and understand why each action is being taken. It was explicitly praised as "such a good workflow."

**How to apply:** Any time there are 3+ sequential steps (PRs, runs, rebases, lab notebook updates, etc.), open with a TodoWrite that captures the full sequence. Update after every completed step.
